# 석판 시뮬레이터

**https://tl-slate.github.io**

토치라이트: 인피니트 **SS13(애프터라이트)** 신격의 석판(Divinity Slate) 보드 배치 시뮬레이터입니다.
게임의 신격 조각상 보드에 석판을 실제로 배치·회전해보고, 각 슬롯에 재능을 붙여 합산 스탯을 바로 확인할 수 있습니다.

## 기능

- **보드 배치**: 왼쪽 팔레트의 석판을 보드로 드래그해서 배치, `R` 키로 회전, 배치한 석판은 드래그로 이동
- **삭제**: 석판 우클릭 / 보드 밖으로 드래그 / 선택 후 `Del` 또는 ✕ 버튼
- **재능 부착**: 석판을 클릭하면 오른쪽에서 신을 고르고 슬롯마다 재능을 검색해서 붙일 수 있습니다
- **합산 스탯**: 붙인 재능의 수치가 자동으로 합산되고, 핵심 재능은 따로 나열됩니다
- **복제 효과**: 빛이 된 나방 / 들불 번지는 순간 / 우주의 균열 / 별들의 고향 4종 레전드 석판의 복제 효과 반영
- **명왕 신격**: 심판(연결선 상 석판 옵션 강화) / 인펙션(인접 석판에 낙인 재능 투영) / 추방 — 정해진 자리에만 배치 가능
- **개수 한도**: 석판 종류별 배치 개수 한도를 넘기면 표시만 하고 계산에서 제외
- **저장/불러오기**: 이름 붙여 저장, 코드로 복사해서 다른 사람과 공유, 저장한 세팅 불러오기

## 데이터

재능 데이터는 [tlidb.com/ko](https://tlidb.com/ko)의 SS13 재능 페이지(신별 6개 + 명왕)를 기준으로 한 한글 실데이터입니다.
붙는 옵션의 정확성은 직접 확인해 주세요.
